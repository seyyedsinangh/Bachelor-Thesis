# Notice

This is an independent standalone research implementation informed by Loïc Cordone's thesis/public work. It is not an official implementation from the original authors.

SANA-FE is an external GPL-3.0 project from the University of Texas at Austin / Sandia collaboration and is installed separately from PyPI. This repository does not vendor SANA-FE source code. The SANA-FE projection uses numerical hardware constants documented in SANA-FE's public Loihi reference architecture and clearly identifies the resulting numbers as simulated/projection estimates.
